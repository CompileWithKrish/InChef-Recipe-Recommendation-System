## 3. Files Safely Removed & Rationales

The following categories were safely purged from the working tree:

### A. Raw Stitch Static Mock HTMLs (21 Files)
- **Files:** `stitch_assets/html/*.html` (7 files) and `stitch_screens/html/*.html` (14 files).
- **Rationale for Safe Removal:** These files were static prototype exports containing hardcoded mock data. They have been fully superseded by the live production HTML files in `src/main/resources/static/` which connect to MySQL via `/api/v1` REST endpoints, implement JWT authentication, and support user state management.

### B. Prototyping Screenshot PNGs (25 Files)
- **Files:** `stitch_assets/images/*_InChef.png` (7 full-page screenshots) and `stitch_screens/screenshots/*.png` (18 screen preview captures).
- **Rationale for Safe Removal:** These were raster screen preview captures generated by the Stitch tool to display visual snapshots during design exploration. They are not referenced by any HTML, CSS, or JavaScript files in the application.

### C. Temporary Download Utility Script (1 File)
- **Files:** `stitch_screens/download_stitch.py`.
- **Rationale for Safe Removal:** A development-only script used during the initial asset download containing hardcoded machine paths. Not part of the runtime or build system.

### D. Standalone Stitch Directories (2 Folders)
- **Folders:** `stitch_assets/` and `stitch_screens/`.
- **Rationale for Safe Removal:** Completely eliminated all top-level Stitch folders so the repository contains only standard, semantic project directories.
